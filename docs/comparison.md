# 同条件对照协议

这份文件定义对照方法；目前没有完成两次独立模型运行，因此没有效果结论。

## 固定输入

使用 [腾讯云公开资料案例](../examples/tencent-cloud-case.md) 的“输入与来源”。两组使用同一模型、同一时间点、同一检索能力和相同的材料包。

- A 组普通提示词：`请根据这份公司、岗位和公开材料，分析这个岗位是否值得继续了解，给出公司理解、岗位价值和面试问题。`
- B 组 Skill 提示词：`使用 $job-jd-due-diligence-v1，根据相同材料分析这个岗位。`

两组分开开启新会话，不把示例报告、评分标准或另一组输出放进输入。保存完整提示词、原始输出、模型版本、时间、工具可用性和检索记录。

## 复核表

| 维度 | 通过标准 | 常见失败 |
|---|---|---|
| 公司针对性 | 用该公司材料解释业务机制 | 换公司名后仍能原样使用 |
| 岗位场景 | 说明决策者、动作、输入、交付及观察方法 | 只列看板、SQL、指标 |
| 证据边界 | 区分披露、推断和内部未知 | 把集团披露当团队条件 |
| 风险判断 | 未知与已证实冲突分开 | 缺资料就判高风险 |
| 验证问题 | 答案可能改变分析或求职判断 | 泛泛询问“公司前景如何” |

每项记录证据句和人工判断，不给无依据的总分。若两组结果差异不明显，也照实记录。一个案例只说明该输入下的表现，不证明跨行业效果。
